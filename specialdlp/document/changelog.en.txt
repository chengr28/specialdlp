Strict DLP Chinese v44006 Update 1 changelog (2024-04-13 ~ 2026-03-31):

* New
  * New Random ModString check
  * Add a new specialdlpTester tool.
* Next generation project and binary roadmap
  * Hardware
    * Enable CPU Spectre mitigations.
    * New ARM64 and ARM64EC architectures support.
    * New CPU instruction set extension requirements:
      * x86: SSE2
      * x64: SSE2
      * ARM64: ARMv8.8-A
      * ARM64EC: ARM64 & x64
    * ARM64EC is now Arm64X PE format.
  * Improve CPU branch prediction of SDC part.
  * Add SHA-3 release checksum.
  * Update to Visual Studio 2026.
  * Notice: SDC Team can't ensure that the binary (including normal version) is able to run normally in an end-of-support Windows. We strongly recommend that you should upgrade to a new system which is still in lifecycle.
* Change
  * Clients which were marked by SDC will show in log, start with <SDC>.
* Fix
  * Standardize file properties.
