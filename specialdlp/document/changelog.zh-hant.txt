Strict DLP Chinese v44006 Update 1 更新日誌 (2024-04-13 ~ 2026-03-31):

* 新增
  * 對 Random ModString 的檢測。
  * 新的檢測工具 specialdlpTester。
* 專案和二進位檔現代化試驗計劃
  * 硬體
    * 啟用對 CPU Spectre 漏洞緩解措施的支援。
    * 添加對 ARM64 和 ARM64EC 架構 CPU 的支援。
    * 升級對 CPU 指令集的要求以提升運算性能，最低的 CPU 指令集要求如下：
      * x86: SSE2
      * x64: SSE2
      * ARM64: ARMv8.8-A
      * ARM64EC: ARM64 & x64
    * ARM64EC 架構下二進位檔將被編譯為 Arm64X PE 格式。
  * 增強 SDC 檢測部分的 CPU 分支預測準確性。
  * 二進位檔校驗添加 SHA-3 的支援。
  * 項目文件升級到 Visual Studio 2026。
  * 注意：SDC Team 無法確保（包括非試驗計劃在內的）二進位檔在生命周期已經結束的 Windows 版本中的正常使用，我們建議您升級到仍在生命週期中的版本。
* 修改
  * 命中 SDC 檢測的用戶端將被標記為以 <SDC> 開頭的記錄。
* 修復
  * 標準化檔案屬性。
